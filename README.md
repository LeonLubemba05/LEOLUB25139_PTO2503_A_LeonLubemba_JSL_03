# JSL03 - Console-Based Task Manager

## 📌 Project Overview
This project is a simple task manager built using JavaScript. It allows users to add up to 3 tasks, validate input, and view all or completed tasks in the console.

## 🚀 Features
- Add up to 3 new tasks
- Input validation for task status
- Auto-generated unique task IDs
- View all tasks in console
- Filter and view completed tasks only

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## ▶️ How to Run
1. Open index.html in a browser
2. Open Developer Console (F12)
3. Follow prompts to add tasks
4. Check console for output
